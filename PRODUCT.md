# Product

## Register

product

## Users

Logistics and operations planners consolidating orders into routed shipments on a desktop workflow. They need to scan, filter, validate, and export results quickly with low cognitive overhead.

## Product Purpose

OM Automation is a Next.js tool for PO PDF extraction and CSV-driven shipment consolidation plus routing. Success looks like faster consolidation, fewer manual errors, and a reliable saved-plan history that can be audited later (tables and map views).

## Brand Personality

Industrial, crafted, fast.

## Anti-references

- Generic SaaS template aesthetics (over-rounded cards, decorative gradients, interchangeable dashboard look)
- Low-contrast UIs that slow scanning and increase mistakes

## Design Principles

- Make scanning effortless, reduce visual noise
- Prefer reliable clarity over decorative styling
- Show the smallest set of controls that keeps power-users fast
- Keep output auditable, state should be legible and explainable

## Accessibility & Inclusion

- No explicit target specified. Default expectation is pragmatic WCAG AA-minded implementation where feasible: keyboard operability, clear focus states, sufficient contrast, and readable type at typical desktop zoom levels.
